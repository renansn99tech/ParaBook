# ParaBook — Quadro Geral

Dashboard público e sanitizado para acompanhamento executivo do ParaBook.

## Atualização semanal

1. Atualize `dist/data/quadro-geral.json`.
2. Não inclua credenciais, dados pessoais, detalhes de vulnerabilidades, URLs internas ou documentos jurídicos restritos.
3. Valide o JSON e confira os filtros localmente.
4. Publique somente depois da revisão das informações por Renan ou Rodrigo.

O projeto não deve ser ligado pela navegação do ParaBook. O caminho inverso, deste dashboard para a plataforma, é intencional.
